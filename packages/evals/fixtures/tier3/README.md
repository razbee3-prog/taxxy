# Tier 3 profiles — PLACEHOLDER DATA

20 fictional contractor profiles generated by `src/scripts/build_tier3_profiles.ts` from the spec's profile matrix. Each holds intake answers, accounts, transactions with expected labels (`ambiguous` = should land in the review queue), the expected review queue, and the expected Q4 2026 worksheet computed by `@taxxy/engine`. They exercise the Tier 3 runner; they are not the donated-data eval set and the expected worksheet is engine-derived, not an external oracle. Income-level buckets: <30k ×5 (includes the two edge profiles), 30–100k ×8, 100–200k ×6, >200k ×1 — the matrix calls for 3 over $200k; add two when real data arrives.
